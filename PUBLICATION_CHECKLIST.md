# Publication checklist

The repository is intentionally private during final review.

Before changing its GitHub visibility to public:

- [ ] review the README, paper date, benchmark counts, and website URL;
- [ ] confirm that no dataset, official solution, or completed rubric is
      present;
- [ ] confirm the licence scope in `LICENSE.md`;
- [ ] run `make check-strict` successfully;
- [ ] manually review the aggregate CSV files for personal or confidential
      fields;
- [ ] create a version tag and GitHub Release;
- [ ] optionally archive the release and add its DOI to `CITATION.cff`.
